Privacy Policy

Information about how AI Resume Analyzer handles resume and application data.

Privacy at a Glance

AI Resume Analyzer is designed to analyze resume documents and provide ATS, resume quality, improvement, analytics, and job compatibility insights.

This page describes the application's current data-handling approach. It is intended as general information and should be reviewed and customized before using the application as a production commercial service.

Information You Provide

  • Resume PDF Used to extract resume information for analysis.
  • Job Description Used when provided to calculate job matching and keyword coverage.
  • Analysis Results Analysis results may be stored locally in the application's SQLite database for history.

Local Storage

The current application stores analysis history locally in its SQLite database. Saved analyses can be viewed and deleted through the Analysis History page.

The application does not require an account or login for its current local usage.

Resume Data

Resume documents can contain sensitive personal information such as names, email addresses, telephone numbers, education, employment history, and other professional information.

Only upload resumes that you are comfortable processing with this application.

Third-Party Services

The current application is intended to operate locally with Flask, Python, and SQLite. If external APIs, cloud storage, analytics services, hosting providers, or other third-party services are added later, this privacy policy should be updated to describe their data handling.

Data Deletion

Saved analysis records can be deleted from the Analysis History page using the Delete option.

Policy Updates

This Privacy Policy may be updated as the application develops or new functionality is introduced.
